# Sistema Financeiro E01/E02 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a base Electron + React + SQLite e conectar os módulos reutilizáveis ArtiSys da etapa 2.

**Architecture:** Desktop local-first com renderer isolado e banco autoritativo no processo principal. `vendor/utilidades` é um submódulo Git pinado; módulos de runtime entram como dependências locais e QA/segurança/release permanecem gates explícitos.

**Tech Stack:** Node 22+, Electron 43, React 19, Vite 8, TypeScript, better-sqlite3, Vitest, módulos ArtiSys locais.

**Spec:** `docs/superpowers/specs/2026-09-12-e01-e02-bootstrap-design.md`

## Global Constraints

- Operação core R$ 0, local-first e sem SaaS obrigatório.
- Node.js >=22.
- Renderer sem acesso direto a Node, filesystem ou SQLite.
- `utilidades` fixado em `1c8d00810dcaa9010330ce7adc2877c90484d17d`.
- Gates pesados de QA/segurança/release são opt-in e não rodam automaticamente em cada alteração.

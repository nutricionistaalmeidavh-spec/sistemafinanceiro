# E03–E05 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar autenticação/RBAC, contas a pagar/receber e cadastros reutilizando os padrões já validados nos repositórios ArtiSys.

**Architecture:** Serviços de domínio no processo principal Electron, SQLite autoritativo, IPC estreito e renderer sem acesso direto a Node/SQL. Mutações exigem sessão e permissão.

**Tech Stack:** Electron, React, TypeScript, SQLite/better-sqlite3, Node crypto.

**Spec:** `docs/superpowers/specs/2026-09-12-e03-e05-core-design.md`

## Global Constraints
- operação local-first e offline;
- nenhuma dependência paga obrigatória;
- dinheiro em centavos inteiros;
- autorização no backend/processo principal;
- cancelamentos e estornos preservam histórico;
- QA/security/release continuam opt-in.

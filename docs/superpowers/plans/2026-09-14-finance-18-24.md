# Financeiro 18–24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar centros de custo/rateios, orçamento/metas, previsto x realizado/cenários, anexos/OCR, aprovações, ações em lote e projeções no aplicativo desktop local-first.

**Architecture:** Adicionar um `planning-service.cjs` dedicado, uma migration incremental e uma página React `PlanningPage.tsx`; IPC/preload apenas expõem contratos estreitos. Financeiro atual permanece fonte de verdade dos lançamentos; planejamento referencia IDs existentes e nunca duplica pagamentos/recebimentos.

**Tech Stack:** Electron, React, TypeScript, Node 22, better-sqlite3/SQLite, módulos ArtiSys locais.

**Spec:** `docs/superpowers/specs/2026-09-14-finance-18-24-design.md`

## Global Constraints
- Core R$ 0 / local-first / self-hosted; nenhum SaaS obrigatório.
- Valores monetários em centavos inteiros.
- Mutações financeiras/administrativas auditadas.
- Sem baixa/pagamento silencioso por aprovação ou OCR.
- Preservar compatibilidade dos lançamentos existentes.
